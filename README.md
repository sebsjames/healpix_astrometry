# Astrometry.net code in a C++ namespace

This is a repo with one file containing the [astrometry.net](https://astrometry.net/downloads/) implementation of healpix routines.

In [mathplot](https://github.com/sebsjames/mathplot) I use the
healpix_bare implementation which I have placed into a module called [healpix_bare.cppm](https://github.com/sebsjames/maths/blob/main/sm/healpix_bare.cppm).

This astrometry code contains some additional features, so I wanted to preserve this modification of the original upstream code.
